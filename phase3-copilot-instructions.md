PROMPT_3_3_A: |
  You are a senior Helm and AKS engineer.

  Generate a complete Helm library chart (type: library)
  that all migrated Spring Boot services will use as a
  dependency.

  LIBRARY CHART STRUCTURE:
  helm-library/
    Chart.yaml          ← type: library
    templates/
      _deployment.yaml  ← Deployment template
      _service.yaml     ← Service template
      _hpa.yaml         ← HorizontalPodAutoscaler
      _pdb.yaml         ← PodDisruptionBudget
      _serviceaccount.yaml  ← ServiceAccount
      _secretprovider.yaml  ← SecretProviderClass (Key Vault)
      _helpers.tpl      ← shared label/name helpers

  REQUIREMENTS PER TEMPLATE:

  _deployment.yaml:
  - apiVersion: apps/v1
  - Labels include Istio injection label:
      sidecar.istio.io/inject: "true"
  - Standard labels: app, version, component, part-of
    (used by Istio VirtualService selectors)
  - LivenessProbe: /actuator/health/liveness  (HTTP)
  - ReadinessProbe: /actuator/health/readiness (HTTP)
  - StartupProbe: /actuator/health (initial delay)
  - Resources: requests and limits from values
  - Environment variables:
      SPRING_PROFILES_ACTIVE from values
      SAP_USERNAME from Key Vault secret ref
      SAP_PASSWORD from Key Vault secret ref
      CORRELATION_ID_HEADER: "X-Correlation-Id"
  - volumeMount for Key Vault CSI secret store
  - terminationGracePeriodSeconds: 60
    (Spring Boot graceful shutdown needs time to drain)
  - lifecycle.preStop hook: sleep 15
    (allow Istio to drain connections before SIGTERM)

  _service.yaml:
  - ClusterIP only (no LoadBalancer — Istio handles ingress)
  - Port name must be "http" (required by Istio for
    protocol detection)

  _hpa.yaml:
  - Scale on CPU (targetAverageUtilization: 70)
  - Scale on memory (targetAverageUtilization: 80)
  - minReplicas and maxReplicas from values
  - stabilizationWindowSeconds: 300 (scale-down)

  _pdb.yaml:
  - minAvailable: 1 (prevent full pod eviction during
    AKS node upgrades)

  _serviceaccount.yaml:
  - Annotate with:
      azure.workload.identity/client-id from values
    (enables Azure Workload Identity for Key Vault access)

  _secretprovider.yaml:
  - provider: azure
  - KeyVault name from values
  - Objects: SAP_USERNAME and SAP_PASSWORD secrets
  - tenantId from values

  _helpers.tpl:
  - Define: migration.labels (common label block)
  - Define: migration.selectorLabels
  - Define: migration.fullname

  OUTPUT: Complete file contents for all 7 files, each
  delimited with:
  # ===== FILE: helm-library/[path] =====
